# Data quality report

Generated by `python -m emporio.quality` from the raw CSVs in `data/` (never edited).
Codes match the assumptions table in the README.

| Code | Finding | Treatment |
|---|---|---|
| A-01 | Product name and description mention different brands | Name, price, stock, status and specs are trusted. The description is hidden from the model for these products. |
| A-02 | Product marked 'coming_soon' was already sold | Status wins for new sales ('launching soon, not on sale yet'). Existing orders stay valid. |
| A-03 | Discontinued product still has stock | Treated as out of the catalog (manual §7.3), with equivalents offered. Leftover stock is flagged to the team here. |
| A-04 | Active product with zero stock | Reported as temporarily unavailable, with similar available alternatives (manual §7.3). |
| A-05 | Order total differs from its items at current prices (order_items has no unit price) | The order total is what the customer paid; current prices never recompute a past order. |
| A-06 | Installment plans below the manual's minimum (§3.1) | Historical, not shown to customers. Every new quote enforces §3.1. |
| A-07 | PIX orders without the 5% discount | Historical (prices or conditions of the time), not shown to customers. |
| A-08 | Customer records that a name lookup would mix up | Customers are identified by the WhatsApp number, never by name. E-mail is only a second check, together with the order number. |
| A-12 | Categories with no products (the manual promises '300+ instruments'; the data has 65) | The agent says it found nothing in the system right now and offers to check with the team. It never says the store does not sell it. |
| A-13 | Promotions: no dates, duplicates per product, campaigns outside the manual's ranges | Only is_active decides. If two were active on one product, the larger discount would win (they don't stack). |
| A-15 | Specs change shape by category and 'strings' has two meanings | Specs are rendered with category-aware labels in Portuguese. |
| A-16 | Shipped order past its estimated delivery (dataset ends on 2026-03-22) | The order tool flags the delay; the agent offers the tracking code and a handoff. |
| A-17 | order_items has no unit price | Orders show items and the order total, never a per-item price. |
